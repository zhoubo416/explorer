# 1. Agent目标

不是回答问题。

目标：

> 理解用户，并推动用户成长。

---

# 2. Agent整体架构

```

用户输入

   |

Conversation Agent


   |

Memory Extractor


   |

Memory OS


   |

Growth Reasoning Engine


   |

Response Generator


   |

主动行为系统

```

---

# 3. Conversation Agent

负责：

正常聊天。

输入：

用户消息。

输出：

自然回复。

---

# 4. Memory Extractor

每次对话后运行。

任务：

判断：

是否产生新记忆。

例如：

用户：

> 最近感觉AI时代压力很大。

提取：

```
{
"type":"emotion",

"content":
"用户担忧AI时代职业变化"

}
```

---

# 5. Memory评分机制

不是所有聊天都保存。

评分：

```
importance =
影响程度
+
长期价值
+
未来参考价值
```

例如：

天气：

0分。

职业方向：

90分。

---

# 6. Growth Reasoning Engine

核心。

输入：

```
目标

+
历史记忆

+
近期行为

+
情绪
```

输出：

```
当前状态

问题

建议
```

---

# 7. AI主动行为系统

每天/每周运行。

流程：

```
定时任务

↓

读取用户状态

↓

分析变化

↓

生成Observation

↓

判断是否触发

↓

发送消息
```

---

# 8. 主动触发规则

## 目标停滞

条件：

```
目标进行中

+

30天无相关行为
```

生成：

> 最近是不是遇到了困难？

---

## 情绪下降

条件：

用户连续表达：

- 没意义
- 放弃
- 累

进入：

成长陪伴模式。

---

## 成长突破

条件：

完成重要事件。

生成：

> 这是你的一个成长节点。

---

# 9. 放弃目标处理Agent

特殊流程。

输入：

用户：

“我不想坚持了。”

Agent：

不能直接修改目标。

流程：

```
情绪确认

↓

原因探索

↓

历史回顾

↓

重新评估

↓

降低目标

↓

继续/调整
```

---

Prompt示例：

```
用户表达想放弃目标。

你的任务：

1. 不立即建议放弃
2. 先理解原因
3. 判断是否为短期情绪
4. 引导用户表达
5. 最后再讨论目标调整
```

# 10. Memory召回策略

回答用户时：

不是读取全部历史。

采用：

```
当前问题

↓

相关目标

↓

相关Memory

↓

近期事件

↓

用户画像
```

---

例如：

用户：

“我是不是不适合创业？”

召回：

```
创业相关目标

过去创业想法

失败经历

成功经验

当前状态
```
